FAQ

Frequently asked questions

Everything you need to know about this Windows taskbar file launcher.

What is FanFolder?

FanFolder is a free Windows 10/11 taskbar utility that shows recent documents collected from Windows Jump Lists, or files and folders from a location you select. Click the FanFolder icon in the taskbar to open items quickly.

How do I install FanFolder with winget?

Open Windows Terminal or PowerShell and run winget install OleBhartvigsen.FanFolder. The Windows Package Manager installs the current version for your user.

Does FanFolder require administrator rights?

No. FanFolder installs per user and does not require administrator privileges or elevation.

Which versions of Windows does FanFolder support?

FanFolder supports Windows 10 version 1809 and later, and Windows 11. Release packages are available for both x64 and ARM64 computers.

Can FanFolder show OneDrive or Dropbox files?

Yes. Point FanFolder at any folder that is available on your computer, including locally synchronised OneDrive, Dropbox, and Google Drive folders.

Can FanFolder show recent documents instead of a folder?

By default FanFolder shows recent documents collected from Windows Jump Lists. The tray-icon Folder submenu also offers Recent files (the Windows Jump List recent list) and Recent Office 365 documents (recent Office/Microsoft 365 files ordered by last-opened time) as one-click choices. A third recent-docs source, ::RecentFiles:: (Explorer's own Recent list), is registry-only — set FolderPath to that value with regedit or PowerShell's Set-ItemProperty.

Are there settings that aren't in the tray menu?

Yes. The tray menu covers folder, sort order, item count, showing folders, and file extensions. Two options are only available in the registry under HKCU\SOFTWARE\FanFolder: FilterRegex (a case-insensitive regular expression matched against filenames — for example \.(pdf|docx?)$ shows only PDF and Word files; leave it empty to show everything) and AnimationStyle (Spring, Fan, Glide, Fade, or None). Edit them with regedit or PowerShell's Set-ItemProperty. See the README on GitHub for the full list of registry settings and PowerShell examples.

Does FanFolder send any telemetry?

Once, after a successful install, FanFolder sends a single anonymous app_installed event to the FanFolder Aptabase project in the EU. It carries only a random per-user id, the app version, CPU architecture, and the platform "Windows" — never filenames, folder paths, or account details. It is sent in the background with a short timeout and is ignored when offline. To opt out before launching, set HKCU\SOFTWARE\FanFolder\TelemetryEnabled (DWORD) to 0. See the Privacy page for full details.

Is FanFolder free?

Yes. FanFolder is free for personal and commercial use forever. Optional support is appreciated but never required.

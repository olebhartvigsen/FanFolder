macOS Stacks on Windows: the real options in 2026

Windows has no native equivalent of the macOS dock Stacks. Here is what the dock clones do, what they miss, and how to get the part of the dock that saves you time.

What Stacks actually are

On macOS, a dock stack is a folder that lives on the dock. Click it and its contents fan out in an arc, or open as a grid or list. The Downloads stack is the one people use constantly. Right-click any dock icon and you get that app's recent documents.

Two separate behaviours are often bundled under the word "dock". One is the look: a bar of icons along the bottom. The other is the Stacks behaviour: click one thing, get a fan of files. The look is widely copied. The behaviour is not.

What the dock clones do

Several good tools put a macOS-style dock on a Windows taskbar. MyDockFinder, ExtraDock and RocketDock all do it, and if the appearance is what you want they work.

None of them read your Windows Jump Lists to build a recent-files fan. They are launchers: they open programs and files you point them at. That is a different job from surfacing what you were working on five minutes ago.

The part nobody ships

Search for "macOS Stacks for Windows" and you will find dock clones, or an answer saying Windows has no equivalent. Both are technically right and practically useless, because the Stacks behaviour is the part that saves time.

Worth being straight about

FanFolder is not a dock clone and does not pretend to be one. It is a tray app that does the fan-of-files thing on the taskbar you already have. If you want the macOS dock bar, a dock clone is the right answer. If you want to stop hunting for the file you had open ten minutes ago, this is.

Getting the useful half

FanFolder covers the Stacks behaviour and the Recents behaviour. Click the icon and recent files fan out from the taskbar in the same gesture as a macOS stack. Right-click a file inside the fan and you get the standard Windows menu.

Point it at Downloads and it behaves like the Downloads stack. Leave it on Recent Documents and it collects from Jump Lists and Explorer's recent files, which is the Windows equivalent of Finder's Recents across every app.

It does not patch explorer.exe, so a Windows feature update cannot break it. That matters if you have been burned by a shell patcher before.

winget install OleBhartvigsen.FanFolder

If you just switched to Windows

The features people miss most after leaving macOS are usually file-related rather than cosmetic: reaching a recent document quickly, and getting to Downloads without opening Explorer. Both are one click with FanFolder.

Windows 11 also removed taskbar toolbars and Quick Launch, which macOS never had, so there is a Windows-specific gap too. The Quick Launch guide covers that one, including the tools that restore the old taskbar if you want the full thing.

If you want the whole macOS look rather than just the useful behaviour, run a dock clone alongside FanFolder. They do not conflict.

Common questions

Is there a way to get the macOS dock on Windows?

Yes, and several tools do it: MyDockFinder, ExtraDock, RocketDock and Start11. They clone the look. None of them read Jump Lists to fan out recent files, which is the Stacks behaviour.

Does FanFolder include a dock?

No. It adds one icon to your existing Windows taskbar and shows a fan of files when you click it. There is no dock bar, and no start menu replacement.

Will it look out of place on Windows?

It uses the Windows taskbar and the standard shell context menu, so it matches the system it runs on. Five animation styles are available if you want the fan to feel different.

Does it work the same on Windows 10?

Yes. It runs on Windows 10 version 2004 or later and Windows 11, on both x64 and ARM64.

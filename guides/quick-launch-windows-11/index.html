How to get the Quick Launch bar and taskbar toolbars back in Windows 11

Windows 11 removed taskbar toolbars and the Quick Launch bar. Here are the real options: ExplorerPatcher, StartAllBack, Start11, and a plain tray app that needs no shell patching.

  • The option that patches nothing

What Windows 11 actually removed

Windows 11 took away two things people had used for years: the Quick Launch toolbar, and the ability to pin folders as taskbar toolbars. The old taskbar let you drag a folder onto it and get a small popup with that folder's contents. That is the behaviour most people miss.

No setting brings it back. This is not a hidden toggle that got flipped. The toolbar support was removed from the shell itself, so there is nothing to re-enable.

The four real options

There are four ways people solve this today. Two restore the old taskbar, one is a commercial taskbar replacement, and one sidesteps the problem.

Why patching explorer.exe is a gamble

ExplorerPatcher and StartAllBack work by injecting code into the Windows shell process. That is how they restore the old taskbar. It works right up until Microsoft changes something the patch depends on, and then the taskbar is broken, or Explorer refuses to start, until the tool ships a fix.

This is not a hypothetical. The recurring theme in support threads about these tools is a broken taskbar after a Windows feature update. If you have ever had a black or empty taskbar after an update, that was the cause.

The fair comparison

All three shell patchers are legitimate tools with real users. If you want the entire Windows 10 taskbar back, ExplorerPatcher is the usual answer and it is free.

The question is whether that is what you are actually after. Most people asking this question want one folder or their recent files within a click. That is a much smaller problem, and it does not require replacing the shell.

The option that patches nothing

FanFolder is a small tray app. Click its icon and the contents of the folder you chose fan out from the taskbar in an arc. Open a file, drag it into another app, or right-click for the normal Windows menu.

Because it is an ordinary application rather than a shell patch, a Windows update cannot break it. It also does not change the rest of your taskbar: clock, system tray, pinned apps and Start all behave exactly as Windows intended.

Point it at Downloads and you have the old Quick Launch behaviour. Point it at a project folder and you have a one-click shortcut to that folder's most recently changed files. Leave it on Recent Documents and it collects what you have been working on across every app.

winget install OleBhartvigsen.FanFolder

Bringing the old taskbar back, if you insist

If you have decided you want the genuine Windows 10 taskbar, install ExplorerPatcher, run it as administrator, pick the Windows 10 option, and sign out or restart. Toolbars come back with it.

Keep a note of how you uninstall it, because you may need it one day:

winget uninstall explorerpatcher

If the taskbar is already broken, boot into Safe Mode, uninstall the patcher there, and restart. That is the standard recovery path.

Common questions

Is the Quick Launch toolbar coming back in a future Windows update?

Microsoft has not announced it. Treat any claim that it is returning as speculation until it ships. The taskbar toolbar code was removed rather than disabled, so restoring it would be a feature addition, not a settings fix.

Does ExplorerPatcher slow Windows down?

It adds work to the shell process, and some users report higher explorer.exe memory use. It is not usually noticeable on a modern machine, but it is more moving parts than a plain tray app.

Can I use both FanFolder and ExplorerPatcher?

Yes. They do not conflict. FanFolder sits on the taskbar as its own icon and does not touch the shell, so the two can run side by side while you decide whether you want to keep the patch.

Will FanFolder show a folder's files in date order?

Yes, and you can change it. Sort by modified date, created date or name, set how many items appear, and filter filenames with a regular expression.

Windows 11 recent files not showing, or the list is empty

Recent files missing in Windows 11? Here is what the setting does, why the list is often empty on a managed PC, how to clear a stale cache, and a way to see recent files anyway.

On this page

  • The one setting that controls it
  • Why the list is empty anyway
  • Fixing a stale or blocked recent list
  • Seeing recent files regardless of policy
  • Pinning files to the taskbar

The one setting that controls it

Windows 11 keeps recently opened files in a list that feeds the Start menu, Jump Lists and File Explorer's Recent folder. One setting governs all of it:

Settings → Personalization → Start → "Show recently opened items in Start, Jump Lists, and File Explorer"

Turn that off and the list stops being recorded. Turn it back on and recording resumes, but files opened while it was off never appear, because they were never written down.

Why the list is empty anyway

The setting being on does not guarantee entries. Four things commonly cause an empty list:

  • Group policy. On a work or school PC an administrator can force the setting off. No local toggle overrides it, and the Settings UI may not even show the option.
  • The app never records anything. Only apps that write recent-file entries show up. Some portable and older programs never do.
  • A stale cache. The folders under %AppData%\Microsoft\Windows\Recent can get into a state where Explorer shows nothing.
  • You are on a fresh profile. A new Windows install, a new user account, or a reset VM genuinely has no history yet. Nothing is broken.
Check this first

If you have just installed Windows or created a new account, an empty recent list is correct behaviour, not a fault. Use your machine for a day and it will fill up. Troubleshooting settings on an empty history wastes your time.

Fixing a stale or blocked recent list

If the setting is on and you have real history that is not showing, clear the cached Recent folders and restart Explorer. Open PowerShell and run:

Remove-Item "$env:AppData\Microsoft\Windows\Recent\*" -Recurse -Force -ErrorAction SilentlyContinue
Stop-Process -Name explorer -Force

Explorer restarts automatically. The recent list rebuilds from scratch as you open files.

If a policy is blocking recording, you can check whether that is the cause:

reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\Explorer" /v NoRecentDocsHistory

A value of 1 means recording is disabled by policy. That is an administrator decision, and changing it needs administrator rights. On a work PC, ask IT. On your own machine, deleting the value restores the default.

Seeing recent files regardless of policy

FanFolder does not depend on that setting. It reads recent-document data that Windows already records and shows it in a fan on the taskbar, so it works on a locked-down work PC where the Start menu list stays empty.

It collects from Windows Jump Lists and from Explorer's recent files, which gives you one list across every app rather than a per-app list. Click the icon and your most recent work is there.

It also works in the other direction. If you want a specific folder rather than a recents list, point FanFolder at it and sort by modified date. That is often the more useful view anyway, since "recent" and "what I am working on now" are not always the same set of files.

Pinning files to the taskbar

Windows 11 does not let you pin individual files to the taskbar, only apps. If you want a document one click from the taskbar, the options are:

  • Drag the file into a folder and point FanFolder at that folder.
  • Pin the app that opens the file, then use that app's Jump List on right-click.
  • Use a launcher. Everything is searchable from the keyboard in a few keystrokes, which beats clicking through a menu for anything you know the name of.

The first option is the one that stays out of your way. A fan of the five or ten files you touched today is usually closer to what you want than a static list.

Common questions

Why does my recent list show files from months ago but not today's?

Usually the recording setting was turned off in between, so the newer files were never written down. Toggle the Start setting off and on, restart, and use the machine for a while to rebuild the list.

Does FanFolder send my file names anywhere?

No. It reads the recent-file data Windows already keeps on your machine and displays it locally. The one optional telemetry event carries no file names or paths, and a registry value turns it off. See the privacy policy for the exact detail.

Can I show recent files from only one app?

Windows Jump Lists do this natively: right-click a pinned taskbar icon and the app's own recent files appear. FanFolder is better when you want one combined list across every app.

Will clearing the Recent folder delete my files?

No. Those folders hold shortcuts and metadata, not the documents themselves. Clearing them only resets the list. Your actual files are untouched.
